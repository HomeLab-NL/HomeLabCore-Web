# HomeLabCore animated flask

- `homelabcore-animated.svg`: self-contained, transparent 194 × 50 SVG; four-second seamless SMIL loop.
- `preview.html`: self-contained browser preview at native size and magnified size.

Uses the existing `assets/brand/homelab-flask.png` embedded unchanged. A blue patch inside the liquid fills the original stationary code cutouts; white coding symbols move subtly over it, clipped to the interior. The flask outline and wordmark remain stationary. Steam rises above the neck. No external requests, libraries, or fonts are required; Segoe UI matches the Windows website brand font, with Arial fallback. Reduced-motion preference shows stationary code and hides steam. The website and Git branches were not changed.
